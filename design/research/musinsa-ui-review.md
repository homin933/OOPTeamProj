## 관찰 → 기존 문제 → 이번 결정

| 관찰된 원칙 | 기존 캠퍼스 데모의 문제 | 이번 설계 |
|---|---|---|
| 검색을 쉽게 찾는 구조 | 헤더에 슬로건만 있어 원하는 주제로 바로 찾기 어려움 | 모든 화면에 검색 입력과 실행 버튼, Enter 지원 |
| 카테고리 이동 경로가 명확함 | 홈·카테고리 모두 동일한 카드 나열 | 홈에 주제 바로가기, 탐색 화면에 선택 상태가 보이는 주제 필터 |
| 반복 목록의 정보 순서가 일정함 | 이미지와 설명만으로 학습량을 판단하기 어려움 | 이미지 → 주제 → 설명 → 문항 수·소요 시간 → 시작 |
| 상품 정보가 우선인 중성 UI | 큰 영문 슬로건이 학습 목적보다 눈에 띔 | 영문 크기를 줄이고 한글 목적 문구를 전면에 배치 |
| 상세 단계와 주요 행동의 일관성 | 문제 종류 전환 후 해설에서 잘못된 화면으로 돌아갈 수 있음 | 직전 문제 유형을 기억하고 돌아가기, 답안 유지 |
| 목적지까지의 복구 경로 제공 | 검색·빈 결과 화면이 없었음 | 검색 결과 수, 빈 결과 안내, 검색·필터 초기화 |
| 데스크톱 화면의 공간 활용 | 모바일처럼 좁은 화면을 그대로 확대할 위험 | 가로 탐색, 4열 주제 목록, 문제/답안 2열, 1080px 최소 너비 |

위 표의 설계 결정은 무신사의 실제 기능을 그대로 복제한 것이 아니라 캠퍼스 퀴즈 목적에 맞춘 해석이다. 추천 순서는 고정 예시이며 인기 순위나 개인화 추천이라고 주장하지 않는다.

## 스타일 규격

- 주 화면: Figma 1200 × 960, Swing 기본 창 1200 × 900. Swing은 운영체제 창 장식과 스크롤을 고려한다.
- 여백: 본문 좌우 40px, 섹션 간 20–24px, 목록 간 16–20px.
- 사각형 버튼, radius 0, 1px 구분선. 그림자·그라데이션 없음.
- 주요 텍스트: Light #111111, Dark #F5F5F5. 배경: Light #FFFFFF, Dark #111111.
- 강조색: Light #2962FF, Dark #82B1FF. 진행 상태와 포커스에 제한적으로 사용.
- Figma: Noto Sans KR Regular/Bold. Swing: Noto Sans CJK KR 우선 및 OS 한글 폰트 대체. 무신사 자체 서체를 확인했다는 뜻이 아니다.
- 이미지: 실제 학교가 지정되지 않아 직접 그린 건물·식당·학사 관련 벡터/Java2D 그림 사용. 전체 UI를 이미지 한 장으로 붙이지 않았다.

## Figma 결과물

[편집 가능한 Figma 파일](https://www.figma.com/design/b3e4TxKb6ZC6HfSOgpK7D2)

- 시작, 추천 홈, 탐색, 객관식, 주관식, 해설, 완료, 기록, 설정, 안내 × Light/Dark = 20개 화면.
- 공통 버튼: Theme × Style × State의 12개 변형과 Label 속성.
- Noto Sans KR 텍스트 스타일 6개, 원시 색상 및 의미별 테마 변수.
- Starter 플랜의 컬렉션당 1모드 제한 때문에 Light/Dark를 별도 컬렉션으로 구성. 업그레이드 없이 두 테마 편집 가능.
- Simple Design System 검색 컴포넌트를 인스턴스로 재사용하고 제품 글꼴·각진 모서리로 조정.
- 주요 메뉴, 문제·해설·완료 이동, 상단 테마 전환 및 설정의 테마 선택을 프로토타입으로 연결.
- 검색창은 탐색 화면으로 진입하는 프로토타입이며 Figma 안에서 실제 키워드 필터링은 하지 않는다. 실제 입력·필터링·초기화는 Swing 데모에서 확인한다.
- 실제 채점이나 기록 저장 없이 UI 구조를 검토하는 데모다.

## 검증

Figma의 화면 캡처로 자동 배치, 헤더 너비, 답안 행 너비, 이미지 비율을 확인하고 수정했다. 화면마다 편집 가능한 텍스트, 컴포넌트 인스턴스, 벡터가 존재한다. Swing은 Java 17 대상으로 컴파일하고 20개 화면을 렌더링했다. EDT에서 검색·필터·빈 결과·초기화·테마 전환 시 입력 유지·해설 복귀 경로를 검증했다. 실제 운영체제 창의 수동 조작은 디스플레이 연결 제한으로 검증하지 못했다.

### 검증 제한 추가 기록

Figma Starter 도구 호출 한도가 마지막 단계에서 소진되어 조사 보드는 Figma에 추가하지 못했다. 이 Markdown이 조사 문서의 최종본이다. 홈과 퀴즈 캡처에서 발견한 답안 행 너비 및 배너 높이 조정은 도구 성공 응답으로 확인했으나, 해당 마지막 변경 후 재촬영과 전체 폰트 자동 감사는 한도 때문에 수행하지 못했다.
